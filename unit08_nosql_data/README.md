# Unit08：非關聯式資料（JSON / TinyDB）範例與練習

本資料夾包含單元 8 中的範例與練習程式，示範 NoSQL 概念、JSON 資料操作、TinyDB 使用等功能。

## 範例檔案

- `example01_json_database.py`：使用 JSON 作為簡單資料庫
- `example02_tinydb_basic.py`：TinyDB 基本操作
- `example03_tinydb_query.py`：TinyDB 查詢操作
- `example04_document_design.py`：文件式資料設計
- `example05_nosql_vs_sql.py`：NoSQL 與 SQL 的比較

## 練習檔案

- `exercise01_json_notes.py`：練習 1 - JSON 筆記本
- `exercise02_tinydb_todo.py`：練習 2 - TinyDB 待辦事項
- `exercise03_blog_system.py`：練習 3 - 簡易部落格系統
- `exercise04_product_catalog.py`：練習 4 - 產品目錄管理

## 安裝 TinyDB

```bash
pip install tinydb
```

## 執行範例（在專案根目錄）

```bash
# 範例檔案
python3 python_advanced/unit08_nosql_data/example01_json_database.py
python3 python_advanced/unit08_nosql_data/example02_tinydb_basic.py
python3 python_advanced/unit08_nosql_data/example03_tinydb_query.py
python3 python_advanced/unit08_nosql_data/example04_document_design.py
python3 python_advanced/unit08_nosql_data/example05_nosql_vs_sql.py

# 練習檔案
python3 python_advanced/unit08_nosql_data/exercise01_json_notes.py
python3 python_advanced/unit08_nosql_data/exercise02_tinydb_todo.py
python3 python_advanced/unit08_nosql_data/exercise03_blog_system.py
python3 python_advanced/unit08_nosql_data/exercise04_product_catalog.py
```

## 資料檔案

範例會自動產生所需的資料檔案：

- `notes.json`：筆記資料
- `todo.json`：待辦事項資料
- `blog.json`：部落格資料
- `products.json`：產品目錄資料
