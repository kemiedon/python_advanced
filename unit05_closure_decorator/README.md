# Unit05：閉包與裝飾器 範例

此資料夾包含教材中「專屬筆記本（閉包）」與「門禁系統（裝飾器）」的可執行範例：

- `closure_example.py`：閉包範例（每位學生專屬計數器）。
- `timeit_example.py`：記錄執行時間的裝飾器範例。
- `require_login_example.py`：門禁裝飾器（檢查是否登入）。

執行範例（在專案根目錄）：

```bash
python3 python_advanced/unit05_closure_decorator/closure_example.py
python3 python_advanced/unit05_closure_decorator/timeit_example.py
python3 python_advanced/unit05_closure_decorator/require_login_example.py
```
