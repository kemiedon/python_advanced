# AI 指令規範書

## 語言規定

- **必須使用繁體中文** 進行所有對話和文檔編寫

## 提交規範

- 每當完成一個任務後，自動 push 到 repository
- Commit 訊息按照以下格式命名：`日期-時間-版本[編號]`
  - 範例：`2025-11-22-17:20:46-1.0[建立專案結構]`
  - 日期格式：YYYY-MM-DD
  - 時間格式：HH:MM:SS（24 小時制）
  - 版本編號：1.0, 1.1, 1.2...（主版本.次版本，按照當日提交次數遞增）
  - 編號說明：用方括號括起來的簡要說明
- 每次 commit 說明需要整理該次更新的內容重點
