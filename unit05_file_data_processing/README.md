# Unit06：檔案與資料處理 範例與練習

本資料夾包含單元 6 中的範例與練習程式，示範檔案讀寫、CSV 處理、JSON 處理、錯誤處理等功能。

## 範例檔案

- `example01_basic_file.py`：基本檔案讀寫操作
- `example02_csv_operations.py`：CSV 檔案處理（讀寫、修改）
- `example03_json_operations.py`：JSON 序列化與反序列化
- `example04_error_handling.py`：錯誤處理與資料驗證
- `example05_data_cleaning.py`：資料清理與轉換

## 練習檔案

- `exercise01_read_write.py`：練習 1 - 讀寫文字檔案
- `exercise02_csv_grade.py`：練習 2 - 處理 CSV 成績資料
- `exercise03_json_backup.py`：練習 3 - JSON 資料備份與還原
- `exercise04_data_validation.py`：練習 4 - 資料驗證與錯誤處理
- `exercise05_integrated_system.py`：練習 5 - 綜合應用（學生成績系統）

## 執行範例（在專案根目錄）

```bash
# 範例檔案
python3 python_advanced/unit06_file_data_processing/example01_basic_file.py
python3 python_advanced/unit06_file_data_processing/example02_csv_operations.py
python3 python_advanced/unit06_file_data_processing/example03_json_operations.py
python3 python_advanced/unit06_file_data_processing/example04_error_handling.py
python3 python_advanced/unit06_file_data_processing/example05_data_cleaning.py

# 練習檔案
python3 python_advanced/unit06_file_data_processing/exercise01_read_write.py
python3 python_advanced/unit06_file_data_processing/exercise02_csv_grade.py
python3 python_advanced/unit06_file_data_processing/exercise03_json_backup.py
python3 python_advanced/unit06_file_data_processing/exercise04_data_validation.py
python3 python_advanced/unit06_file_data_processing/exercise05_integrated_system.py
```

## 資料檔案

範例會自動產生所需的測試資料檔案，包括：

- `sample_data.txt`：範例文字檔
- `students.csv`：學生成績 CSV 檔
- `students_backup.json`：JSON 備份檔
- `cleaned_data.csv`：清理後的資料檔
